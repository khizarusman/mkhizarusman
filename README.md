## Selected Case Study

### AI Dental Receptionist
**Conversational AI + Workflow Automation**

**Technologies:** Vapi · n8n · Webhooks

**Project Type:** Functional Automation Prototype

### Business Challenge

Dental clinics frequently handle routine phone enquiries and appointment-related requests while managing daily front-desk operations.

This project explores how an AI-powered voice assistant and automated workflows can support these processes.

### Solution Architecture

The system combines an AI conversational interface with workflow orchestration.

**Conceptual workflow:**

Caller → Vapi AI Voice Agent → Integration Trigger → n8n Automation → Configured Actions

### Implementation Approach

**1. Conversational AI**

Configured a Vapi-based voice assistant to support simulated dental clinic conversations.

**2. Workflow Integration**

Connected the conversational interface with n8n to enable automated process execution.

**3. Automation Design**

Structured workflow stages to process information and coordinate configured actions.

**4. Integrated Demonstration**

Developed a connected prototype demonstrating how conversational AI and workflow automation can work together.

### Technical Value

- Workflow automation design
- Integration between independent platforms
- Practical business-process problem solving
